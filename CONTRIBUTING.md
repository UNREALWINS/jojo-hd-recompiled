# Contributing

Thanks for helping improve JoJo HD Recompiled.

## Do not upload original game data

Never submit:

- `default.xex` or other XEX files;
- ISO/XISO/disc images;
- extracted package contents;
- original textures, audio, movies, fonts or artwork;
- archives containing commercial game data.

This applies to commits, pull requests, issues, comments and attachments.

## Good bug reports

Please include:

- clear reproduction steps;
- Windows version;
- CPU/GPU where relevant;
- launcher settings;
- crash address/function;
- diagnostic log excerpts;
- hashes rather than copies of original game files.

## Code changes

Keep project-authored code and generated game-derived code clearly separated.

Do not commit large generated recompilation output derived from the commercial executable.

Compatibility fixes should preferably be expressed as:

- local generation/patch tooling;
- small independently authored overrides;
- machine-readable metadata;
- documentation of addresses and behavior.

## Pull requests

Explain:

1. what problem the change fixes;
2. how to reproduce the old behavior;
3. how you tested the new behavior;
4. whether the change affects compatibility with ReXGlue versions.
